1단계. Chrome에 설치하기

Chrome은 파일을 내려받아 직접 설치합니다. 순서대로 천천히 따라 하세요.

1설치 파일 내려받기

  1. GitHub 페이지를 엽니다.
  2. 초록색 Code 버튼을 누르고 Download ZIP을 누릅니다.

2압축 풀기

다운로드 폴더에서 받은 ZIP 파일의 압축을 풉니다. kidsnote-backup-main 폴더가 생깁니다.

이 폴더를 지우면 확장 프로그램이 동작하지 않습니다. 문서 폴더처럼 지우지 않을 곳으로 옮겨 두세요.

3개발자 모드 켜기

  1. Chrome 주소창에 chrome://extensions를 입력하고 Enter를 누릅니다.
  2. 오른쪽 위 개발자 모드를 켭니다.

4폴더 불러오기

  1. 왼쪽 위 압축해제된 확장 프로그램 로드를 누릅니다.
  2. kidsnote-backup-main 폴더를 선택합니다.
폴더를 열었을 때 manifest.json 파일이 바로 보이는 폴더가 맞는 폴더입니다.

5아이콘을 툴바에 꺼내 두기

주소창 오른쪽의 퍼즐 모양 버튼을 누릅니다.

KidsNote Backup 줄의 핀을 누릅니다.

주소창 옆에 K 아이콘이 생깁니다.

여기까지 되면 성공: 주소창 옆에 K 아이콘이 보입니다.

KidsNote Backup은 키즈노트 공식 프로그램이 아니며, 본인 계정으로 볼 수 있는 자료를 개인적으로 백업하는 도구입니다. 자료는 외부 서버로 전송되지 않고 내 컴퓨터에만 저장됩니다.
