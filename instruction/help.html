문제 해결

화면에 나온 문구나 증상을 아래에서 찾아 보세요.

증상해결 방법
K 아이콘이 안 보여요주소창 옆 퍼즐 모양 버튼을 눌러 KidsNote Backup을 찾으세요. 없으면 1단계 설치를 다시 진행하세요.
“1단계에서 KidsNote 화면을 먼저 열어주세요”지금 탭이 키즈노트가 아닙니다. 키즈노트 탭으로 이동한 뒤 K 아이콘을 다시 누르세요.
“KidsNote 페이지와 연결할 수 없습니다”키즈노트 탭을 새로고침(F5)한 뒤 다시 시도하세요.
“Child ID를 찾지 못했습니다”로그인 상태를 확인하고 추억보기 → 알림장 목록을 연 뒤 새로고침하고 자동 감지를 다시 누르세요.
“추억보기 전환을 확인하지 못했습니다”키즈노트 화면에서 추억보기를 직접 누른 뒤 다시 시도하세요.
“원/반 정보를 자동으로 찾지 못했습니다”키즈노트의 알림장이나 앨범 화면을 한 번 연 뒤 다시 시도하세요.
“KidsNote API request failed”로그인이 풀렸을 수 있습니다. 다시 로그인한 뒤 이어받기를 누르세요.
“시작일은 종료일보다 늦을 수 없습니다”시작일이 종료일보다 앞서도록 날짜를 고치세요.
멈춘 것 같아요오래전 자료를 찾는 중일 수 있습니다. 잠시 기다려도 숫자가 그대로면 일시정지 후 이어받기를 누르세요.
실패 숫자가 0이 아니에요일부 파일을 받지 못했습니다. 끝난 뒤 같은 기간으로 한 번 더 백업하세요.
다운로드 허용 창이 떠요허용을 누르세요. 파일을 한 번에 많이 받을 때 나오는 정상 안내입니다.
Chrome에서 개발자 모드 경고가 나와요직접 설치한 확장 프로그램에 나오는 안내입니다. 번거로우면 Edge 스토어 버전을 사용하세요.
그래도 안 되면 GitHub Issues에 오류 문구를 남겨 주세요. 아이 이름, 사진, Child ID는 올리지 마세요.
← 처음으로
KidsNote Backup은 키즈노트 공식 프로그램이 아니며, 본인 계정으로 볼 수 있는 자료를 개인적으로 백업하는 도구입니다. 자료는 외부 서버로 전송되지 않고 내 컴퓨터에만 저장됩니다.
