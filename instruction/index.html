KidsNote Backup 초간단 안내

빨간 번호만 순서대로 따라 하세요. 사진은 크롬 기준입니다. 사용하는 브라우저의 설명을 따르세요.

1다운로드

GitHub 열기 → Code → Download ZIP → 받은 ZIP 압축 풀기

2설치

크롬브라우저: 주소창에 chrome://extensions → 개발자 모드 켜기 → 압축해제된 확장 프로그램 로드 → kidsnote-backup-main 폴더 선택

엣지브라우저: 주소창에 edge://extensions 입력 → 개발자 모드 켜기 → 압축 풀린 파일 로드(Load unpacked) → kidsnote-backup-main 폴더 선택

3알림장 열기

크롬브라우저: 크롬에서 키즈노트 로그인 → 추억보기 → 알림장 → 새로고침 → 퍼즐 아이콘 → KidsNote Backup

엣지브라우저: 엣지에서 키즈노트 로그인 → 추억보기 → 알림장 → 새로고침 → 확장 아이콘 → KidsNote Backup

4백업 설정

① 자동 감지 → ② 시작일 → ③ 종료일 → ④ 저장 항목 → ⑤ 사진 저장 방식

5시작하고 사진 확인

백업 시작 → 저장 창이 뜨면 저장 → 완료 후 다운로드 폴더 → KidsNote → 자녀 이름 → Photos

크롬브라우저: 다운로드 확인 chrome://downloads
엣지브라우저: 다운로드 확인 edge://downloads
