키즈노트 사진과 알림장을 내 컴퓨터에 백업하기

처음이어도 괜찮습니다. 아래 4단계를 순서대로 따라 하면 됩니다.

전체 순서

  1. 설치 - 브라우저에 확장 프로그램을 추가합니다. (처음 한 번만)
  2. 연결 - 키즈노트에 로그인하고 확장 프로그램을 엽니다.
  3. 백업 - 기간을 고르고 다운로드 버튼을 누릅니다.
  4. 확인 - 다운로드 폴더에서 파일을 확인합니다.
준비물: PC(Windows 또는 Mac), Microsoft Edge 또는 Google Chrome, 키즈노트 아이디와 비밀번호. 휴대폰에서는 사용할 수 없습니다.

어떤 브라우저를 쓰시나요?

눌러서 1단계 설치를 시작하세요. 둘 다 있다면 설치가 쉬운 Edge를 권장합니다.

추천 · 공식 스토어Microsoft Edge버튼 몇 번으로 설치가 끝납니다. Windows PC에는 보통 기본으로 들어 있습니다.  Google Chrome파일을 내려받아 직접 설치합니다. 조금 더 복잡합니다.

이미 설치하셨나요?

2단계 연결로 바로 가기 · 문제 해결 보기

KidsNote Backup은 키즈노트 공식 프로그램이 아니며, 본인 계정으로 볼 수 있는 자료를 개인적으로 백업하는 도구입니다. 자료는 외부 서버로 전송되지 않고 내 컴퓨터에만 저장됩니다.
