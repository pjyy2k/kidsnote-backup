Microsoft Edge 공식 스토어 버전

KidsNote Backup 설치 및 사용 안내

Edge 사용자는 ZIP 파일이나 개발자 모드 없이 Microsoft Edge Add-ons에서 바로 설치할 수 있습니다.

1공식 스토어에서 설치

아래 버튼을 Microsoft Edge에서 누르세요.

Microsoft Edge Add-ons에서 설치

  1. 스토어 페이지에서 다운로드(Get) 버튼을 누릅니다.
  2. 확인 창이 나오면 확장 추가를 누릅니다.
공식 스토어 버전은 개발자 모드와 수동 업데이트가 필요하지 않습니다.

2확장 프로그램 고정

  1. Edge 주소창 오른쪽의 확장 프로그램(퍼즐 모양) 아이콘을 누릅니다.
  2. KidsNote Backup을 찾습니다.
  3. 옆의 고정 아이콘을 눌러 주소창 옆에 항상 보이게 합니다.
설치했는데 아이콘이 안 보이면 먼저 퍼즐 모양의 확장 프로그램 메뉴를 확인하세요.

3KidsNote 로그인

  1. KidsNote 웹사이트에 접속해 로그인합니다.
  2. 알림장 화면을 한 번 엽니다.
  3. 주소창 옆의 KidsNote Backup 아이콘을 누릅니다.
처음 실행할 때알림장 화면을 먼저 열어두면 Child ID와 원/반 정보를 자동으로 찾기 쉽습니다.

4자녀 정보 확인

확장 프로그램에서 자동 감지를 누릅니다. Child ID가 자동으로 입력되면 정상입니다.

자동 감지가 되지 않으면 KidsNote 알림장 화면을 새로고침한 뒤 다시 시도하세요.

5백업 기간과 저장 방식 선택

  1. 시작일 / 종료일을 선택합니다.
  2. 알림장은 원본 사진, JSON, Markdown 중 원하는 항목을 선택합니다.
  3. 사진을 날짜별 폴더에 저장할지 한 폴더에 모두 저장할지 선택합니다.

6알림장 또는 앨범 다운로드

알림장 다운로드알림장 원본 사진과 선택한 JSON/Markdown 데이터를 저장하고, 완료 후 HTML 리포트를 생성합니다.
앨범 다운로드앨범 게시물에 첨부된 원본 사진을 일괄 다운로드합니다. 알림장 사진과 섞이지 않도록 별도 Album 폴더에 저장합니다.
오래전 자료를 선택하면 해당 기간까지 탐색하는 데 시간이 걸릴 수 있습니다. 화면이 잠시 멈춘 것처럼 보여도 진행 상태를 확인해 주세요.

7일시정지 / 이어받기 / 취소

다운로드 중에는 일시정지, 이어받기, 취소를 사용할 수 있습니다.

이미 Edge 다운로드 시스템에 전달된 파일은 일시정지나 취소 직후에도 다운로드가 완료될 수 있습니다.

8저장된 파일 확인

파일은 Edge의 기본 다운로드 폴더 아래 KidsNote 폴더에 저장됩니다.

KidsNote/ └─ ChildName/ ├─ Photos/ ← 알림장 사진 ├─ Diary/ ← Markdown ├─ JSON/ ← JSON ├─ Reports/ ← HTML 리포트 └─ Album/ └─ Photos/ ← 앨범 사진
KidsNote Backup은 사용자가 로그인한 KidsNote에서 직접 접근할 수 있는 자료를 개인적으로 백업하기 위한 도구입니다. KidsNote의 공식 확장 프로그램은 아닙니다.
