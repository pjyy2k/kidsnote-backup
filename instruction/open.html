2단계. 키즈노트와 연결하기

확장 프로그램이 내 아이 정보를 찾도록 키즈노트 화면을 열어 줍니다. 여기부터는 Edge와 Chrome이 같습니다.

1키즈노트 로그인

키즈노트 웹사이트를 열고 로그인합니다.

설치 전에 이미 열어 둔 키즈노트 탭이 있다면 꼭 새로고침(F5) 하세요.

2알림장 화면 열기

  1. 왼쪽 메뉴 위쪽의 추억보기를 누릅니다.
  1. 알림장을 누릅니다.

3K 아이콘 누르기

키즈노트 화면이 열린 상태에서 주소창 옆의 K 아이콘을 누르면 아래와 같은 창이 열립니다.

키즈노트가 아닌 다른 탭에서 열면 백업이 시작되지 않습니다. 그럴 때는 이 창의 KidsNote 알림장 열기 버튼을 누른 뒤, 열린 화면에서 K 아이콘을 다시 누르세요.

4자녀 정보 확인

Child ID 칸에 숫자가 들어 있는지 봅니다. 비어 있으면 자동 감지를 누릅니다.

여기까지 되면 성공: Child ID 칸에 숫자가 보입니다. 숫자 값은 아이마다 다릅니다.
